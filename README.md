# Nilson Cardoso Portfolio

Minimal, multi-page personal portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Pages

- Home
- About
- Projects
- Experience
- Education

## Features

- Responsive layout
- Light / dark mode
- PT / EN language switcher
- Expandable project details with native `<details>`

## Before publishing

1. Add your real CV PDF at `assets/yourname-CV.pdf`.
2. Replace `YOUR_EMAIL@example.com` in `index.html` with your email.
3. Replace the LinkedIn placeholder URL with your profile.
4. Add project screenshots to `assets/` when ready.
5. Review the final project descriptions and dates.
