# Nilson Cardoso Portfolio

Minimal, multi-page personal portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Pages

- Home
- About
- Projects
- Experience
- Education

## Features

- Responsive layout
- Light / dark mode
- PT / EN language switcher
- Expandable project details with native `<details>`
- No framework required

## Before publishing

1. Add your real CV PDF at `assets/Nilson-Cardoso-CV.pdf`.
2. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
3. Replace the LinkedIn placeholder URL with your profile.
4. Add project screenshots to `assets/` when ready.
5. Review the final project descriptions and dates.

## GitHub Pages

Push the files to the repository root and enable GitHub Pages from the repository's Pages settings, using the branch and `/ (root)` folder.
